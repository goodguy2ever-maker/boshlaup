# Investor Mode & Dealflow Module (Архив для Фазы 2)

Этот модуль был временно отключен из активного интерфейса для V1 релиза, чтобы платформа оставалась легкой, понятной и не отпугивала начинающих фаундеров метриками (MRR, раунды, оценка).

Все компоненты, стили и связи сохранены и готовы к включению в один клик.

## Как включить обратно в будущем (Фаза 2):
1. Откройте `lib/config.ts`
2. Поменяйте:
```typescript
export const FEATURES = {
  ENABLE_INVESTOR_MODE: true, // Включить
};
```
3. Все кнопки, таблицы, поля ввода в визарде и инвесторские панели автоматически вернутся на свои места в интерфейсе!

## Содержимое модуля:
- `InvestorTable.tsx` — таблица сделок с колонками MRR, Трэкшн, Раунд и доля, прямые контакты.
- `InvestorContactModal.tsx` — модальное окно прямого контакта с фаундером через Telegram.
- Схема базы данных `schema.prisma` сохраняет все поля (`investorAsk`, `investorEquity`, `investorUseOfFunds`, `mrrMetrics`, `userMetrics`), так что данные никуда не пропадут.
